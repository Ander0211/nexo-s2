PASO 1 — Instalar Python (solo la primera vez)
----------------------------------------------
En el Símbolo del sistema copie ESTA línea completa y pulse Enter:

  winget install Python.Python.3.12 --accept-package-agreements --accept-source-agreements

Si winget no existe:
  1. Abra https://www.python.org/downloads/
  2. Descargue e instale.
  3. MARQUE la casilla "Add python.exe to PATH".
  4. Install Now.

CIERRE la ventana negra y ábrala de nuevo.


PASO 2 — Comprobar Python
-------------------------

Debe decir Python 3.12 (o 3.13). Si dice que "py" no se reconoce,
Python no quedó en el PATH: repita el PASO 1 y reinicie el PC.
